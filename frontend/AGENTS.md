# MAISON frontend

The website is a framework-free HTML, CSS, and JavaScript application served by the Express backend.

## Files

- `public/index.html`: application shell
- `public/app.js`: page rendering, navigation, and API interactions
- `public/styles.css`: responsive layout and component styles
- `public/images/`: static images

The browser communicates with the backend using the `/api` endpoints. Start the website and API together from `backend/server` with `npm run dev`.
